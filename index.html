Quick guide

Logic: Place an Input, a gate, and an Output. Select Connect, then tap the source and destination.

Test: Press Test. Tap Input parts to toggle 0/1. Gates update automatically.

Data: Connect multiple input bits through logic gates to build your own binary systems.

Save: Save downloads a JSON file. Export/Import lets you move builds between devices.
